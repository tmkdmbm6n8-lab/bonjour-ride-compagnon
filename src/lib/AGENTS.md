- A sealed `ride_archives` row is the only source of a record's historical fields (`sealedParts` in `admin-ride-record.js`); erased contacts/booking stay unavailable and are never rebuilt from current profiles, and the admin list goes through the `admin_ride_index` RPC so archives without a `rides` row stay listed by Paris day.
- Server functions (`createServerFn`) must live in `.ts` files such as `src/lib/vtc.functions.ts`; the dev server does not register them from `.js` files ("Server function info not found"). Web fonts load via `<link>` in `__root.tsx`, not `@import` in `src/styles.css`.
- React Native calls `/api/public/native/$`: only POST auth/login and auth/refresh bootstrap sessions without a bearer, using fresh publishable clients and camelCase sessions with millisecond expiry; all business paths verify the bearer before `handleVtc` with the same RLS/roles, preventing anonymous business access. Mobile code never contains server secrets.
- Favorite driver / private clients: pure rules in `src/lib/private-client-policy.js`, server operations in `src/lib/private-clients.server.js`; links only through the `manage_favorite_driver` RPC as the rider, which requires a completed ride together or an unexpired scanned QR claim. A ride booked with `favorite: true` gets `favorite_driver_id` and the `private` dispatch phase (`PRIVATE_OFFER_SECONDS` in `vtc-dispatch.js`), then falls back to ordinary dispatch; card bookings keep the choice in `card_bookings.favorite_driver_id`. QR tokens travel in the URL fragment (`/join#invite=`) and only their SHA-256 is stored, so they never reach logs.
- Address search (`vtc-geocoding.server.js`) tries Google first, then falls back to Géoplateforme BAN + Photon/OSM on quota (429/OVER_QUERY_LIMIT, which pauses Google up to 1 h per server instance) or any Google error; the privacy page names these backups, so change both together. Route fallback is unchanged to keep fares untouched.
- Offline launch: src/lib/offline-shell.ts is the only service-worker registrar (vite-plugin-pwa generateSW, NetworkFirst pages, refused in previews); iOS WKWebView runs it only with WKAppBoundDomains + limitsNavigationsToAppBoundDomains.
